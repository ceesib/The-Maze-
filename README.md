Maze Algorithms Visualizer
A Java project for generating and solving mazes using different algorithms, with animated visualizations.

Currently, the project supports:

DFS Maze Generator (recursive backtracker)

DFS Maze Solver (depth-first traversal with path cleanup)

The project is being expanded into a larger framework where multiple generation and solving algorithms can be plugged in, compared, and visualized.

🚀 Project Goals
This project started as a simple DFS maze generator/solver, but is evolving into a playground for exploring algorithms, OOP design, and SOLID principles.

The key goals are:

Implement multiple maze generation algorithms.

Implement multiple solving algorithms.

Visualize each step of the process (both generation and solving).

Compare algorithms based on performance and path quality.

Build a clean, modular design that follows OOP & SOLID practices.

🔨 Planned Features
Maze Generation Algorithms
✅ Recursive Backtracker (DFS)

⏳ Prim’s Algorithm

⏳ Kruskal’s Algorithm

⏳ Eller’s Algorithm

⏳ Aldous-Broder Algorithm

⏳ Recursive Division

Maze Solving Algorithms
✅ Depth-First Search (DFS)

⏳ Breadth-First Search (BFS)

⏳ Dijkstra’s Algorithm

⏳ A* Search (with heuristics like Manhattan & Euclidean)

Visualization
Step-by-step animations for both generation and solving.

Color-coded highlighting of explored vs. final path.

Option to run the same maze through multiple solvers and compare results.

Extensions
Weighted mazes (walls or paths with costs).

Show shortest vs. longest path.

Display metrics: nodes visited, path length, solve time.

🧑‍💻 Why This Project?
This project isn’t just about mazes — it’s a learning playground:

Algorithms: Hands-on with graph search and pathfinding.

OOP: Separate responsibilities for generators, solvers, and visualization.

SOLID Principles: Flexible design where new algorithms can be added without breaking existing ones.

Visualization: See abstract concepts like DFS, BFS, or A* come alive.

📚 Future Roadmap
Refactor into a framework with MazeGenerator and MazeSolver interfaces.

Implement additional algorithms for both generation and solving.

Add a UI to select and compare algorithms dynamically.

Explore performance trade-offs between algorithms.
